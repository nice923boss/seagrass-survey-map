## 二、輸出結構 surveys.json

```jsonc
{
  "generatedAt": "2026-07-22T02:00:00.000Z",  // 產生時間
  "source": "csvPublic",                        // csvPublic | sheetsApi
  "points": [
    {
      "pointId": 1,
      "name": "點位1",
      "surveys": [                               // 依日期新到舊排序
        {
          "date": "2026-07-18",                 // 調查日期 YYYY-MM-DD
          "submittedAt": "2026-07-18T16:00:21+08:00",
          "surveyor": "曾明堂/郭三賢",           // 調查人員
          "recorder": "齊奐",                    // 記錄人員
          "sections": [                          // 分區欄位（見第四節）
            { "title": "Ａ樣框覆蓋率", "fields": [ { "label": "…[海草]", "value": "40%" } ] }
          ],
          "photoGroups": [                       // 分組照片
            { "label": "Ａ樣框照片", "photos": [ { "fileId": "1dLj…", "thumb": "https://…", "full": "https://…" } ] }
          ]
        }
      ]
    }
  ]
}
```

## 三、值的正規化規則

| 項目 | 原始 | 轉換後 | 規則 |
|---|---|---|---|
| 調查點位 | `點位１`、`點位１０` | `pointId: 1`、`10` | 抽全形數字(０-９)轉半形整數 |
| 調查日期 | `2026/4/11` | `2026-07-18` 式 `YYYY-MM-DD` | 以 `/` 切分後月、日補零 |
| 時間戳記 | `2026/4/11下午4:00:21` | `2026-04-11T16:00:21+08:00` | 解析上午/下午轉 24 小時制，固定 +08:00 |
| 照片儲存格 | `open?id=A, open?id=B` | `[{fileId,thumb,full}]` | 逗號/空白/換行分隔多網址，正則抽 file ID |

> 調查日期漏填時，退回以「時間戳記」的日期部分為準(表單時間戳記恆有值)。
> 照片欄的樣框字母半形(A/B)與全形(Ｃ)混用，分組時一律兩者都比對(避免 A/B 樣框照片遺失)。

Drive 網址轉換(見 `src/data/drivePhotos.ts`):
- 縮圖 `https://lh3.googleusercontent.com/d/<ID>=w400`、大圖 `=w1600`(drive.google.com/thumbnail 端點對「檔案回應」資料夾常整批失效，故用 lh3)。
- file ID 正則涵蓋 `open?id=`、`file/d/<ID>/`、`uc?id=`、`thumbnail?id=`、`lh3/d/<ID>` 五式。

照片本地化(見 `scripts/downloadPhotos.ts`):抓取時下載並壓縮成 webp(長邊 1600)存進 `public/assets/photos/<fileId>.webp`，`thumb`/`full` 改指向本地路徑;下載失敗者保留 lh3 網址 fallback。增量下載，已存在則跳過。可用 `DOWNLOAD_PHOTOS=false` 停用。

## 四、欄位分組(pattern 判定，有序，第一個命中者勝)

不用欄位位置硬編碼(兩表順序不同)，改以欄名關鍵字分組，容忍表單日後新增欄位。

**記錄層級欄位(抽出，不進 sections):**
| 欄名關鍵字 | 對應 |
|---|---|
| `時間戳記` | submittedAt |
| `調查日期` | date |
| `調查點位` | pointId / name |
| `調查人員` | surveyor |
| `記錄人員` | recorder |

**照片(欄名含 `照片` 或 `上傳`)歸 photoGroups:**
| 欄名再含 | photoGroup label |
|---|---|
| `樣框`(Ａ/Ｂ/Ｃ) | `Ａ/Ｂ/Ｃ樣框照片` |
| `水質` | `水質照片` |
| `水生物` | `水生物照片` |
| `樣本` | `樣本照片` |
| 其他 | `其他照片` |

**分區 sections(依序):**
| 區塊標題 | 命中關鍵字 |
|---|---|
| 基本資訊 | `天候狀況`、`潮汐`、`放網時間`、`點位調查時間` |
| Ａ樣框覆蓋率 | 含 `Ａ樣框`(非照片) |
| Ｂ樣框覆蓋率 | 含 `Ｂ樣框` |
| Ｃ樣框覆蓋率 | 含 `Ｃ樣框` |
| 整體觀察 | 含 `整體觀察` |
| 水質 | 含 `水溫`/`鹽度`/`pH`/`亞硝酸`/`硝酸`/`氨氮`/`水質採樣`/`底質採樣`/`水質狀況` |
| 水生物調查 | 含 `傘籠`/`長城籠`/`水生物處理`/`補充紀錄` |
| 植株與物候 | 含 `株數`/`葉長`/`庇護高度`/`物候` |
| 其他 | 未匹配者，僅在值非空時保留 |

空值欄位一律略過，不顯示。

## 五、兩表差異(已知，正規化須容忍)

- A 表獨有:`放網時間`、傘籠與長城籠水生物調查、`水生物處理方式`、`其他補充紀錄`、水生物照片。
- B 表:無水生物調查；`株數`分「卵葉鹽草」「線葉二藥草」兩欄；水質區塊排在物候之後。
- A 表末兩欄 `第 64 欄`、`第 56 欄` 為表單殘留未命名欄，通常為空，歸「其他」並因空值略過。
- pattern 分組對兩表皆適用，不需為 B 表另寫邏輯。

## 六、驗證規則(`scripts/validate.ts`，失敗即中止並回傳非零)

1. 每列「調查點位」可解析且落在 1-10，否則報錯附列號。
2. 每列「調查日期」可解析為合法 `YYYY-MM-DD`，否則報錯。
3. 至少一筆有效資料。
4. 未匹配任何 section 的未知欄位:僅印警告，不中止(容忍表單演進)。
